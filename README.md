# Retail Sales Dashboard (Excel Project)
## Overview
Built an interactive dashboard in Microsoft Excel to analyze retail sales performance.
## Tools Used
- Advanced Excel
- XLOOKUP
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
## Key Insights
- October highest revenue month
- Product 1 top performer
- Green Bay highest city revenue
- Strong profit margin
